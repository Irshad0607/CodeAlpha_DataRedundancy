How It Works
SHA-256 fingerprinting
Each record is normalised and hashed. The 64-char hex digest is the canonical identity of that record.
Cosmos DB lookup
The hash is queried against the existing index before any write is attempted.
Duplicate rejection
Matching hash means the record is rejected. No write occurs. User receives a 409 response.
